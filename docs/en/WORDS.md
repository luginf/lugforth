# Words of Lugforth

The words of the Linux build (`out/posix/lugforth`) and of the web build (`out/web/lugforth.js`), as the interpreters themselves list them.

Generated by `tools/words_reference.py`, which asks the interpreters for their
words, so nothing here can be missing (run it again after adding words: see
docs/en/dev/PITFALLS.md). The descriptions come, in this order, from the reference
pages `attic/oldsite/*.html`, from short notes in `tools/words_notes.py`, and
from the stack comments and bindings in the Forth sources. A word of the ANS Forth standard that the project does not describe is
marked *ANS*: it does what the standard says (see the links below).

The columns: **Word**, **Stack** effect, **What it does**, and where the word
exists: **P** Linux (POSIX) build, **W** web build.

## Other places to read about the words

* The [Lugforth site](https://luginf.github.io/lugforth/), and the original
  [uEforth](https://github.com/flagxor/ueforth) it comes from (the reference pages of
  `attic/oldsite/` are the source of many descriptions here).
* [ESP32forth glossary](https://esp32forth.forth2020.org/glossary), a spreadsheet
  kept by the community, and the
  [v7.5 list of words](https://esp32forth.wordpress.com/esp32forth-v-7-5-list-of-words/),
  which repeats the reference pages.
* [esp32.arduino-forth.com](https://esp32.arduino-forth.com/index/glossaire), in
  French: a glossary and a lexicon per version
  (for example [v7.0712](https://esp32.arduino-forth.com/article/lexiqueESP32forthV70712)),
  with a help page for each word. It follows ESP32forth, the same language on the
  ESP32, so it also covers hardware words that this build does not have.
* [ANS Forth standard](https://forth-standard.org/standard/words), for the
  standard words.
* The SDL2 words are in [docs/en/SDL2-words.md](SDL2-words.md).

## The `forth` vocabulary

612 words. 62 are described by the reference pages, 162 by the notes, 207 are standard words the project leaves to the standard, 169 have only a stack comment or binding, 12 have no description yet.
