[web version](demo/terminal.html) (the Forth console itself).

## Run your own file

Any game file of the examples also runs in the console page with
`terminal.html?run=gfx_roguelike.fs`. Several files are separated by
commas: `?run=2048.fs,gfx_2048.fs`.
